# Audio Assets — Hybrid Audio Engine
# Convention: {letter_name}_{vowel}.mp3
#
# Examples:
#   ba_fatha.mp3  → صوت بَ
#   ba_kasra.mp3  → صوت بِ
#   ba_damma.mp3  → صوت بُ
#   ba_name.mp3   → اسم الحرف "باء"
#
# When no .mp3 file exists for a sound, TtsService
# automatically falls back to device TTS engine.
